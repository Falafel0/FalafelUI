# Архитектурная спецификация: Единый интерактивный холст (Unified Canvas Studio)
## Объединение Text2Img + Img2Img + Inpainting + Upscale в единую рабочую среду

> **Статус**: Архитектурный проект & План внедрения  
> **Файл**: `docs/UNIFIED_CANVAS_STUDIO_SPEC.md`  
> **Концепция**: "Photoshop для генеративного AI" — единое бесконечное/документное рабочее пространство со слоями, локальным контекстным баром и динамическим определением типа генерации.

---

## 1. Концепция и ментальная модель (UX Paradigm)

### Проблема классических интерфейсов (Automatic1111 / ComfyUI / MooshieUI legacy)
Традиционные AI-интерфейсы искусственно делят творческий процесс на четыре изолированных экрана:
1. `txt2img` — генерация картинки с нуля.
2. `img2img` — отправка картинки во вторую вкладку для перерисовки.
3. `inpainting` — отправка в третью вкладку для закрашивания маски.
4. `upscale` — отправка в четвертую вкладку для увеличения разрешения.

Пользователь вынужден постоянно *"пересылать"* изображения из одного режима в другой через контекстные меню (`Send to Inpaint`, `Send to Img2Img`), теряя контекст, историю и слои.

### Решение: Единый холст (Unified Canvas Studio)
Вместо переключения режимов пользователь находится в **едином графическом редакторе**. Тип операции определяется **состоянием холста, наличием маски и положением рамки генерации (Bounding Box)**:

```
                                  [ РАМКА ГЕНЕРАЦИИ (1024x1024) ]
                                                │
                 ┌──────────────────────────────┼──────────────────────────────┐
                 ▼                              ▼                              ▼
          [ Пустой холст ]            [ Под рамкой есть пиксели ]       [ Нарисована маска ]
                 │                              │                              │
                 ▼                              ▼                              ▼
         Режим: Text-to-Image          Режим: Image-to-Image             Режим: Inpainting
        (генерация с нуля)            (Denoise 0.2 - 0.9)              (Generative Fill)
                                                │                              │
                                                ▼                              ▼
                                      [ Рамка шире слоя ]             [ Выбран инструмент 🔍 ]
                                                │                              │
                                                ▼                              ▼
                                      Режим: Outpainting                Режим: Upscale
                                      (Generative Expand)             (Hi-Res Fix / Detail)
```

## 2. Автоматическое определение действия (State Machine)

Когда пользователь нажимает `Generate` (или `Ctrl+Enter`), холст вычисляет операцию автоматически по следующему алгоритму:

```typescript
export type UnifiedCanvasAction = 
  | "txt2img"    // Пустая рамка или чистый холст + промпт
  | "img2img"    // Рамка поверх растрового слоя, маски нет, Denoise < 1.0
  | "inpaint"    // Активная маска внутри рамки (Generative Fill)
  | "outpaint"   // Рамка выходит за границы растрового слоя (Generative Expand)
  | "upscale";   // Пользователь запросил увеличение разрешения выделенной области
```

### Таблица условий резолвера

| Состояние холста под рамкой | Активная маска | Denoise | Действие системы | Что передается в ComfyUI |
|---|---|---|---|---|
| **Пусто (прозрачность)** | Нет | Любой | **Text-to-Image** | Стандартный txt2img KSampler с латентом `EmptyLatentImage(W, H)`. |
| **Растровое изображение** | Нет | `< 1.0` | **Image-to-Image** | Кроп пикселей под рамкой -> VAE Encode -> KSampler с заданным `denoise`. |
| **Растровое изображение** | **Есть (кисть/лассо)** | `0.1 - 1.0` | **Inpainting** | Кроп пикселей + Ч/Б маска -> VAE Encode (inpaint model/nodes) -> бесшовное сведение. |
| **Частично за пределами картинки** | Любая | Любой | **Outpainting** | Кроп с добавлением паддинга прозрачности -> Feathering маски -> генерация фона. |
| **Выделен слой / регион** | Нажата кнопка `2x/4x` | — | **Upscale** | Кроп пикселей -> Model Upscale / Ultimate SD Upscale -> новый Upscale-слой. |

## 3. Архитектура системы слоев (Photoshop-like Layer Stack)

Слои поддерживают профессиональные параметры композитинга:

### 3.1. Структура слоя (`CanvasLayer`)
```typescript
export type CanvasLayerBlendMode = 
  | "normal" 
  | "multiply" 
  | "screen" 
  | "overlay" 
  | "darken" 
  | "lighten"
  | "color-dodge"
  | "color-burn";

export interface CanvasLayer {
  id: string;
  name: string;
  type: "raster" | "mask" | "adjustment";
  visible: boolean;
  opacity: number;       // 0.0 - 1.0
  locked: boolean;
  order: number;
  blendMode: CanvasLayerBlendMode;
  
  // Геометрия трансформации (Move / Free Transform)
  x: number;
  y: number;
  width?: number;
  height?: number;
  rotation?: number;
  scaleX?: number;
  scaleY?: number;
}
```

### 3.2. Операции со слоями
1. **Режимы наложения (Blend Modes)**:
   - `Multiply` — для наложения теней, скетчей и контуров.
   - `Screen` — для наложения световых эффектов, магии, свечения.
   - `Overlay` — контрастное смешивание текстур.
2. **Дублирование (`Duplicate`)**:
   - Быстрое клонирование слоя для недеструктивных экспериментов (`Ctrl+J`).
3. **Объединение вниз (`Merge Down`)**:
   - Сведение активного слоя со слоем под ним (`Ctrl+E`).
4. **Сведение видимых (`Flatten / Merge Visible`)**:
   - Запекание всех видимых растровых слоев в один финальный слой (`Ctrl+Shift+E`).
5. **Маска слоя (Layer Mask)**:
   - Рисование маски кистью или лассо, привязанное к конкретному слою.

## 4. Неразрушающая генерация (Staging & Variations Carousel)

Когда завершается генерация (или апскейл), результат **не перезаписывает холст мгновенно**. 
Он попадает в **Staging Area (Буфер вариантов)**:

```
┌─────────────────────────────────────────────────────────────┐
│                       ХОЛСТ (CANVAS)                        │
│                                                             │
│         ┌─────────────────────────────────┐                 │
│         │     [ Сгенерированный вариант ] │                 │
│         │                                 │                 │
│         └─────────────────────────────────┘                 │
│         ┌─────────────────────────────────┐                 │
│         │ ◀ [ Вариант 2 из 4 ] ▶           │                 │
│         │ [✓ Принять (Enter)] [✗ Отмена]  │                 │
│         │ [+ Новый слой]                  │                 │
│         └─────────────────────────────────┘                 │
└─────────────────────────────────────────────────────────────┘
```

- **Принять (`Enter`)**: Запекает выбранный результат в активный слой (или заменяет маскированную область).
- **В новый слой (`Shift+Enter`)**: Создает отдельный растровый слой над текущим.
- **Отклонить (`Esc`)**: Возвращает холст в исходное состояние без изменения слоев.

## 5. Контекстная панель задач (Contextual HUD Bar)

По аналогии с Contextual Task Bar в современном Photoshop, под рамкой генерации отображается плавающая компактная панель:

```
[ 🪄 1girl, cyberpunk city, neon... ] [ ✨ Generate ] [ Denoise: 0.75 ] [ 🔍 2x Upscale ] [ ⚙️ ]
```

- **Если рамка пуста**: Показывает `✨ Generate` (txt2img).
- **Если под рамкой есть картинка**: Автоматически появляется ползунок `Denoise` и кнопка `✨ Transform`.
- **Если нарисована маска**: Кнопка меняется на `✨ Infill / Fill`.
- **Кнопка `🔍 2x / 4x Upscale`**: Мгновенно отправляет область под рамкой в апскейлер с наложением результата на холст с сохранением позиционирования.

## 6. План поэтапной интеграции в кодовую базу FalafelUI

### Фаза 1: Расширение структуры `CanvasStore` (Выполнено)
- Добавление `blendMode`, `x`, `y`, `rotation`, `scale` в `CanvasLayer`.
- Методы: `setLayerBlendMode`, `duplicateLayer`, `mergeDownLayer`.
- Селектор автоматического режима: `detectUnifiedAction()`.

### Фаза 2: Обновление UI слоев (`LayerPanel` & `LayerItem`)
- Внедрение выпадающего списка режимов наложения (`Blend Mode`) и ползунка прозрачности.
- Кнопки дублирования и объединения слоев в тулбаре слоев.

### Фаза 3: Единая кнопка генерации на холсте
- Интеграция `GenerateButton` с автоопределением операции: генерация не требует переключения режимов в верхнем меню `ALL_MODES`.
- Добавление прямого действия `Upscale Selection` на холсте.
